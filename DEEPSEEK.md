# DeepSeek CLI Project Context

DeepSeek CLI is an open-source AI coding assistant that brings the power of DeepSeek (V4 Flash & V4 Pro Thinking) directly into the terminal. It is an unofficial adaptation of Google's Gemini CLI created by sluisr.

## Project Overview

- **Purpose:** Provide a seamless terminal interface for DeepSeek models, supporting code understanding, generation, automation, and MCP integration.
- **Creator:** sluisr (https://sluisr.com)
- **Main Technologies:**
  - **Runtime:** Node.js (>=20.0.0)
  - **Language:** TypeScript
  - **UI Framework:** React (using Ink for CLI rendering)
  - **Bundling:** esbuild
  - **Model Architecture:** DeepSeek V4 Flash / DeepSeek V4 Pro
